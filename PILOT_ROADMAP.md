# KENWELL TX Platform: 90-Day Pilot Deployment Roadmap
**Target Environment**: KENWELL-TX-ORG Platform Ecosystem  
**Timeline Window**: Q4 2026 Strategy Execution  

## 🏗️ Phase 1: Foundation & Gateway Isolation (Days 1–30)
Focus on establishing secure routing layers and stabilizing database clusters.

*   **Days 1–10: Stack Harmonization**
    *   Deploy the dual-stack server architecture persistently under PM2 monitor structures.
    *   Bind the `kenwell-tx-python-proxy` layer (Port 8000) to isolate the database engine.
*   **Days 11–20: Data Contracts Integration**
    *   Verify the SQLite tables auto-initialize and index incoming schema records flawlessly.
    *   Conduct structural stress tests on the `POST /api/trade/classify` nomenclature endpoints.
*   **Days 21–30: Security Access Audit**
    *   Review local SSH signature keys and enforce explicit CORS allowance domain limits.
    *   Enforce anonymous Git code signing policies across all local organizational workspaces.

## 🤖 Phase 2: AI Chatbot Integration & UI Polish (Days 31–60)
Focus on linking the interactive browser views to the live proxy pipelines.

*   **Days 31–40: Gateway Channel Wireup**
    *   Connect the standalone `chatbot.ui` web elements straight to the Python proxy handlers.
    *   Ensure telemetry heartbeat notifications stream back to the UI ledger instantly.
*   **Days 41–50: Search Ledger Optimization**
    *   Build interactive search bars and sort filters into the React TypeScript data views.
    *   Optimize JSON payload parsing routines to prevent front-end crash exceptions.
*   **Days 51–60: Pre-Flight Internal Sandbox Run**
    *   Perform end-to-end user transactions within a small, isolated staff testing sandbox group.
    *   Audit Cockpit system diagnostics charts on Port 9090 for CPU or memory resource leaks.

## 🚀 Phase 3: Targeted Pilot Operational Launch (Days 61–90)
Focus on pushing the platform live to chosen user groups and refining system telemetry.

*   **Days 61–75: Controlled Pilot Ring Release**
    *   Onboard the first circle of active external user partners into the compliance platform views.
    *   Monitor data pipeline traffic throughput to ensure transaction tracking speeds match targets.
*   **Days 76–85: Compliance Review**
    *   Confirm all processed commodities compile to proper 8-digit ASEAN AHTN codes.
    *   Extract full automated database back-ups to lock in permanent audit trail trails.
*   **Days 86–90: Full Production Sign-off**
    *   Compile feedback metrics logs to scale hardware requirements for subsequent feature waves.
    *   Push finalized structural code blueprints live to the main enterprise master branches.
